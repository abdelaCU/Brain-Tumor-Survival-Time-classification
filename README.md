# Brain Tumor Survival Classification (MLOps Project)

## Overview
This project predicts patient survival class based on MRI images and other features.

## Problem Type
3-class Classification:
- Short Survival
- Medium Survival
- Long Survival

## Features
- Deep learning-based classification
- REST API using FastAPI
- Modular code structure
- Ready for Docker deployment

## Tech Stack
- Python
- TensorFlow / PyTorch
- FastAPI
- Docker (planned)

## Data
Datasets are not included due to size and privacy.
